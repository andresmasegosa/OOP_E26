# Session 4 — Study session

Today is for working through material from sessions 1–3. Bring your code and notes. There is no new Java topic.

## Exercise 0 — choose your starting point

Open the exercise sheet for the latest session you have not finished. Write down the first task you still need to do and the question that stops you. Work on that task, then run your own code and compare the result with what you expected.

## Exercise 1 — compare the chess designs

Put your cost-of-change notes from sessions 1, 2 and 3 side by side. If a line is missing, return to that session’s exercise and complete it. Use the three versions of the chess game to explain, in your own words, what changed and what remained difficult.

## Exercise 2 — transfer

If your chess work is complete, choose a problem from the session 3 introductory assignments. Sketch the classes and responsibilities before coding. Bring one design decision to discuss with the teaching team.

Continue from your own work. Andrés and the TA will circulate and help with questions. The interfaces material begins in session 5.
